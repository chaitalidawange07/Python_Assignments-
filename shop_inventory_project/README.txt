SHOP INVENTORY DATA ANALYSIS & DASHBOARD

Files:
- shop_inventory_analysis.py : runnable Python program
- shop_data.csv              : synthetic sample dataset for immediate execution
- console_output.txt         : console output from the included sample data
- dashboard_output.png       : four-chart dashboard created by the program
- Project_Report.pdf         : mini project report
- Code_Print.pdf             : print-friendly code appendix
- Output_Print.pdf           : print-friendly console output

Run:
  pip install pandas numpy matplotlib scikit-learn
  python shop_inventory_analysis.py

Keep the .py and .csv files in the same folder. The sample CSV is synthetic, not real shop data.
